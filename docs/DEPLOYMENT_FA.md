# راه‌اندازی مرحله‌ای XAU AI Supervisor

این راهنما برای اتصال کامل از طریق Cloudflare و گوشی هم قابل انجام است؛ برای مسیر پیش‌فرض داده طلا به ویندوز یا MT5 دسکتاپ نیاز نداری. Worker، D1 و ربات تلگرام در حساب Cloudflare مستقر شده‌اند. منبع داده بازار از طریق API ابری وصل می‌شود، اما تأیید اکوییتی حساب معاملاتی/پراپ هنوز مرحله‌ای جداگانه است.

## ۱) پایگاه داده D1

در Cloudflare باید دیتابیس `xau-ai-supervisor` و شناسه آن در `wrangler.toml` تنظیم شده باشد. جدول‌ها با migration داخل پوشه `migrations` ساخته می‌شوند. از آنجا که Worker فعلاً فعال است، شناسه یا تنظیمات موجود را بی‌دلیل تغییر نده.

## ۲) Secretها

در Worker مسیر **Settings → Variables and Secrets** این Secretها استفاده می‌شوند:

- `INGEST_SECRET`: کلید احراز هویت دریافت داده از MT5 و مسیرهای مدیریتی.
- `TELEGRAM_BOT_TOKEN`
- `TELEGRAM_CHAT_ID`
- `TELEGRAM_WEBHOOK_SECRET`
- `SIFTING_API_KEY`: کلید API بازار Commodities در SiftingIO؛ فقط داخل Cloudflare Worker Secret ذخیره شود.

مقادیر را داخل GitHub، کد یا گفتگوی ChatGPT قرار نده. توکن یا Secret را در تصویر صفحه هم نمایش نده.

## ۳) Webhook تلگرام

Worker به‌صورت خودکار webhook را با Bot API تنظیم می‌کند. برای امنیت، مقدار `TELEGRAM_WEBHOOK_SECRET` ابتدا با SHA-256 به رشته hex سازگار با محدودیت تلگرام تبدیل می‌شود؛ همان مقدار هش‌شده هم در هدر ورودی بررسی می‌شود. بنابراین لازم نیست Secret را دستی در BotFather یا جای دیگری کپی کنی.

پس از استقرار، دستورهای `/start` و `/status` باید پاسخ بدهند.

## ۴) اتصال خودکار قیمت طلا بدون کامپیوتر شخصی

مسیر پیش‌فرض پروژه، دریافت داده XAUUSD از SiftingIO در خود Cloudflare Worker است. این روش به MT5 دسکتاپ، ویندوز، VPS یا روشن‌ماندن گوشی احتیاج ندارد.

### ساخت کلید رایگان SiftingIO

1. از مرورگر گوشی وارد [صفحه ثبت‌نام SiftingIO](https://sifting.io/register) شو.
2. حساب رایگان بساز و ایمیل را تأیید کن.
3. در داشبورد، بازار **Commodities** را به حساب اضافه کن و پلن **Free** را انتخاب کن.
4. در بخش API Keys یک کلید بساز. کلید را فقط برای خودت نگه دار؛ آن را اینجا یا در تلگرام نفرست.

صفحه‌های رسمی راهنما:
- [XAUUSD و دسترسی رایگان](https://sifting.io/symbols/commodities/XAUUSD)
- [پلن رایگان و سهمیه](https://sifting.io/free-market-data-api)
- [مستندات کندل‌های OHLCV](https://sifting.io/docs/historical/commodities)

### افزودن کلید به Cloudflare

1. وارد [Cloudflare Dashboard](https://dash.cloudflare.com/) شو.
2. از **Workers & Pages**، Worker با نام xau-ai-supervisor را باز کن.
3. وارد **Settings → Variables and Secrets** شو.
4. در بخش Secrets گزینه افزودن Secret را بزن.
5. نام را دقیقاً SIFTING_API_KEY قرار بده و کلید ساخته‌شده در SiftingIO را در Value وارد کن.
6. Save کن. مقدار کلید را در GitHub، کد، عکس صفحه یا چت وارد نکن.

پس از ذخیره، endpoint وضعیت Worker باید marketDataConfigured: true را نشان دهد:
[وضعیت Worker](https://xau-ai-supervisor.novarw0hnqiw.workers.dev/health)

### رفتار دریافت داده و سهمیه

- Worker هر ۵ دقیقه یک درخواست REST می‌فرستد و کندل‌های بسته‌شده یک‌دقیقه‌ای XAUUSD را می‌گیرد.
- از همان داده‌ها فقط کندل‌های کامل ۵ و ۳۰ دقیقه‌ای ساخته می‌شوند؛ اگر دقیقه‌ای جا افتاده باشد، آن کندل تجمیعی ساخته نمی‌شود.
- حداکثر ۲٬۰۰۰ کندل یک‌دقیقه‌ای در شروع دریافت می‌شود. این حجم برای حداقل ۵۵ کندل ۳۰دقیقه‌ای در شرایط پیوسته کافی است؛ اگر بازار وقفه یا شکاف داده داشته باشد، شرط تعداد کندل باز هم باید جداگانه بررسی شود.
- تحلیل زمان‌بندی‌شده هر ۵ دقیقه انجام می‌شود. بنابراین داده پایه M1 است، اما سامانه پایش پیوسته و لحظه‌به‌لحظه‌ی یک‌دقیقه‌ای ندارد.
- پلن رایگان SiftingIO اکنون ۱۰٬۰۰۰ درخواست REST در ماه دارد. دریافت هر ۵ دقیقه حدود ۸٬۶۴۰ درخواست در ماه ۳۰روزه و ۸٬۹۲۸ درخواست در ماه ۳۱روزه مصرف می‌کند. درخواست‌های دستی /analyze هم ممکن است در مصرف سهمیه اضافه شوند.
- پلن رایگان برای مصرف شخصی/داخلی غیرتجاری است و SLA تضمین‌شده ندارد؛ محدودیت‌ها و شرایط روز ارائه‌دهنده را پیش از استفاده دوباره بررسی کن.

### محدودیت مهم قیمت

قیمت XAUUSD این سرویس یک نرخ تجمیعی/مرجع از چند منبع است؛ قیمت دقیق قابل معامله در بروکر تو نیست و ممکن است با آن تفاوت داشته باشد. فیلد حجم نیز شمارش تغییرات قیمت (tick count) است، نه حجم رسمی معاملات بورس. این فید برای تحقیق و هشدار استفاده می‌شود؛ برای اجرای سفارش یا تعیین قیمت ورود واقعی باید با نمودار و قیمت بروکر خودت تطبیق داده شود.

## ۴-ب) اکوییتی و افت روزانه حساب

SiftingIO فقط داده بازار می‌دهد؛ به موجودی، اکوییتی، معاملات باز یا محدودیت زیان پراپ‌فرم تو دسترسی ندارد. بنابراین این اطلاعات به‌صورت خودکار از فید قیمت به دست نمی‌آیند.

تا وقتی منبع معتبر اکوییتی و مبنای روزانه وصل نشده باشد، موتور وضعیت ریسک را «تأییدنشده» نگه می‌دارد و هیچ سیگنالی صادر نمی‌کند. مقدار اکوییتی یا افت روزانه را حدس نمی‌زنیم. بعد از فعال‌شدن قیمت بازار، این بخش را با روش read-only جداگانه تکمیل می‌کنیم.

### پل اختیاری MT5

فایل اکسپرت [XAU_AI_Supervisor.mq5](../mt5/XAU_AI_Supervisor.mq5) و [راهنمای آن](MT5_BRIDGE_FA.md) برای حالتی نگه داشته شده که بعداً به MT5 دسکتاپ یا VPS ویندوزی دسترسی داشته باشی. برای مسیر پیش‌فرض فعلی لازم نیست.

## ۵) وضعیت سیگنال و محدودیت ایمنی

Worker ابتدا تقویم رسمی رویدادهای مهم آمریکا را از BLS، BEA و Federal Reserve دریافت می‌کند و در صورت مسدودشدن آن‌ها از XOOMAR با درج انتساب داده استفاده می‌کند. استفاده رایگان XOOMAR برای مصرف شخصی/داخلی است و برای کاربرد تجاری کافی نیست. جزئیات، محدودیت‌ها و رفتار توقف امن در [راهنمای تقویم اقتصادی](MACRO_CALENDAR_FA.md) آمده است. اگر هر منبع خراب یا قدیمی باشد، snapshot معتبر جایگزین نمی‌شود و پس از منقضی‌شدن داده قبلی، نتیجه باید `NO_TRADE` باقی بماند. جهت DXY و بازده اوراق ۱۰ساله هنوز به سیستم متصل نشده‌اند.

تا زمانی که اتصال واقعی و صحت داده‌ها بررسی نشده، از خروجی برای معامله واقعی استفاده نکن. قبل از استفاده عملی باید داده‌های بروکر با نمودار MT5 تطبیق داده، خطاهای قطع اتصال و بازگشت بررسی و عملکرد سیستم در حساب دمو آزمایش شود.

## ۶) حدود رایگان بودن

پل MT5 از قیمت فید بروکر خودت استفاده می‌کند و هزینه API داده جداگانه ندارد؛ اما به کامپیوتر روشن و اینترنت متصل نیاز دارد. Cloudflare Workers و D1 در پلن رایگان سقف استفاده دارند و نامحدود نیستند. سرویس تقویم اقتصادی یا داده کلان ممکن است سهمیه یا هزینه مستقل داشته باشد. هیچ API پولی بدون تصمیم جداگانه اضافه نمی‌شود.
