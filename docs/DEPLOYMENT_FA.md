# راه‌اندازی مرحله‌ای XAU AI Supervisor

این راهنما برای راه‌اندازی در حساب Cloudflare خودت است. Worker، D1 و ربات تلگرام در حساب تو مستقر شده‌اند؛ اتصال داده بازار و ثبت مبنای ریسک باید روی ترمینال MT5 دسکتاپ انجام و آزمایش شود.

## ۱) پایگاه داده D1

در Cloudflare باید دیتابیس `xau-ai-supervisor` و شناسه آن در `wrangler.toml` تنظیم شده باشد. جدول‌ها با migration داخل پوشه `migrations` ساخته می‌شوند. از آنجا که Worker فعلاً فعال است، شناسه یا تنظیمات موجود را بی‌دلیل تغییر نده.

## ۲) Secretها

در Worker مسیر **Settings → Variables and Secrets** این Secretها استفاده می‌شوند:

- `INGEST_SECRET`: کلید احراز هویت دریافت داده از MT5 و مسیرهای مدیریتی.
- `TELEGRAM_BOT_TOKEN`
- `TELEGRAM_CHAT_ID`
- `TELEGRAM_WEBHOOK_SECRET`

مقادیر را داخل GitHub، کد یا گفتگوی ChatGPT قرار نده. توکن یا Secret را در تصویر صفحه هم نمایش نده.

## ۳) Webhook تلگرام

Worker به‌صورت خودکار webhook را با Bot API تنظیم می‌کند. برای امنیت، مقدار `TELEGRAM_WEBHOOK_SECRET` ابتدا با SHA-256 به رشته hex سازگار با محدودیت تلگرام تبدیل می‌شود؛ همان مقدار هش‌شده هم در هدر ورودی بررسی می‌شود. بنابراین لازم نیست Secret را دستی در BotFather یا جای دیگری کپی کنی.

پس از استقرار، دستورهای `/start` و `/status` باید پاسخ بدهند.

## ۴) اتصال داده بازار و اکوییتی از MT5

برای رعایت شرط رایگان‌بودن، مسیر اصلی دریافت قیمت، فید XAUUSD خود بروکر در MT5 است؛ در نتیجه به API جداگانه بازار کالا و اشتراک پولی آن وابسته نیستیم.

راهنمای کامل نصب:
[`docs/MT5_BRIDGE_FA.md`](MT5_BRIDGE_FA.md)

فایل اکسپرت:
[`mt5/XAU_AI_Supervisor.mq5`](../mt5/XAU_AI_Supervisor.mq5)

نکته‌ها:
- فقط **MT5 دسکتاپ** می‌تواند Expert Advisor اجرا کند؛ MT5 Android نمی‌تواند.
- EA باید روی نمودار نماد طلای بروکر (نمادی که نامش شامل `XAUUSD` یا `GOLD` باشد) اجرا شود.
- در تنظیمات EA مقدار فعلی `INGEST_SECRET` را وارد کن؛ آن را برای من ارسال نکن.
- در تنظیمات MT5، آدرس Worker را در فهرست مجاز WebRequest قرار بده.
- ترمینال باید متصل و روشن بماند تا کندل‌های تازه و اکوییتی ارسال شوند.
- اکسپرت فقط داده می‌خواند و هیچ سفارش معاملاتی ثبت، تغییر یا بسته نمی‌کند.

### مبنای افت روزانه

مبنای اکوییتی ابتدای روز بر اساس UTC ذخیره می‌شود. اکسپرت آن را حدس نمی‌زند یا در میانه روز با اکوییتی فعلی جایگزین نمی‌کند. اگر برای روز جاری مبنای ذخیره‌شده‌ای وجود نداشته باشد، وضعیت ریسک تا نیمه‌شب UTC بعدی تأیید نمی‌شود. این رفتار ممکن است شروع تحلیل را به تأخیر بیندازد، اما از پنهان شدن افت قبلی روز جلوگیری می‌کند.

## ۵) وضعیت سیگنال و محدودیت ایمنی

حتی پس از اتصال کندل‌ها و اکوییتی، موتور تا زمانی که زمینه کلان و تقویم اقتصادی معتبر و تازه دریافت نکند، سیگنال BUY/SELL صادر نمی‌کند. در نبود هر داده ضروری، نتیجه باید `NO_TRADE` باقی بماند.

تا زمانی که اتصال واقعی و صحت داده‌ها بررسی نشده، از خروجی برای معامله واقعی استفاده نکن. قبل از استفاده عملی باید داده‌های بروکر با نمودار MT5 تطبیق داده، خطاهای قطع اتصال و بازگشت بررسی و عملکرد سیستم در حساب دمو آزمایش شود.

## ۶) حدود رایگان بودن

پل MT5 از قیمت فید بروکر خودت استفاده می‌کند و هزینه API داده جداگانه ندارد؛ اما به کامپیوتر روشن و اینترنت متصل نیاز دارد. Cloudflare Workers و D1 در پلن رایگان سقف استفاده دارند و نامحدود نیستند. سرویس تقویم اقتصادی یا داده کلان ممکن است سهمیه یا هزینه مستقل داشته باشد. هیچ API پولی بدون تصمیم جداگانه اضافه نمی‌شود.
