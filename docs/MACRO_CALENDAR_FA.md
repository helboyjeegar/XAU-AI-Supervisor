# تقویم اقتصادی رسمی برای XAU AI Supervisor

این نسخه برای محافظت زمانی در برابر انتشارهای مهم آمریکا از منابع عمومی و رسمی استفاده می‌کند؛ API key یا اشتراک تقویم پولی لازم نیست.

## منابع

- **Bureau of Labor Statistics (BLS)**: فید iCalendar رسمی برای زمان‌بندی CPI، PPI و Employment Situation. BLS اعلام می‌کند تقویم آنلاین شامل زمان‌بندی بیشتر انتشارهای خبری دفتر ملی است و معمولاً جمعه‌ها به‌روزرسانی می‌شود.
  - https://www.bls.gov/schedule/news_release/bls.ics
- **Bureau of Economic Analysis (BEA)**: فایل JSON رسمی release dates. سیستم فقط GDP و Personal Income and Outlays (که انتشار PCE در آن است) را از این فایل انتخاب می‌کند.
  - https://apps.bea.gov/API/signup/release_dates.json
- **Federal Reserve**: صفحه رسمی جلسات FOMC برای سال‌های جاری و آینده. سیستم روز دوم جلسه را روز انتشار سیاست در نظر می‌گیرد.
  - https://www.federalreserve.gov/monetarypolicy/fomccalendars.htm

## رفتار فنی

- Worker هر پنج دقیقه اجرا می‌شود؛ تقویم رسمی حداکثر هر ۱۵ دقیقه یک‌بار تازه‌سازی می‌شود.
- زمان رویدادها به UTC یکسان‌سازی می‌شود.
- برای FOMC، زمان بیانیه ساعت ۱۴:۰۰ و نشست خبری ساعت ۱۴:۳۰ به وقت نیویورک فرض شده است. صفحه رسمی فدرال رزرو تاریخ جلسات را مشخص می‌کند؛ این دو ساعت، زمان‌بندی معمول هستند و فرض نرم‌افزار محسوب می‌شوند.
- موتور فقط برای ۱۵ دقیقه قبل یا بعد از رویدادهای شناسایی‌شده، مانع ورود می‌شود.
- اگر دریافت هر یک از منابع قطع شود، محتوای ناقص جایگزین snapshot قبلی نمی‌شود. وقتی snapshot قبلی از حد تازگی ۳۰ دقیقه عبور کند، تحلیل باید به `NO_TRADE` برگردد.
- اگر منبع BEA بیش از ۶۰ روز از آخرین به‌روزرسانی اعلام‌شده‌اش گذشته باشد یا رویدادهای آینده کافی در آن نباشد، sync ناموفق محسوب می‌شود.
- رویدادهای BLS که در این نسخه به‌عنوان پرریسک شناسایی می‌شوند: CPI، PPI و Employment Situation.
- رویدادهای BEA: GDP و Personal Income and Outlays.
- رویدادهای FOMC: بیانیه و نشست خبری.

## محدودیت‌های فعلی

این منبع فقط **زمان‌بندی رویدادها** را پوشش می‌دهد؛ مقدار واقعی داده‌های اقتصادی، غافلگیری نسبت به پیش‌بینی، جهت DXY و بازده اوراق ۱۰ساله هنوز به سیستم متصل نشده‌اند. بنابراین این تقویم به‌تنهایی جهت BUY یا SELL تعیین نمی‌کند.

این نسخه همه خبرهای ممکن بازار را پوشش نمی‌دهد. اخبار اضطراری، سخنرانی‌های ناگهانی، تغییرات برنامه انتشار و رویدادهایی که در این سه منبع نیامده‌اند ممکن است شناسایی نشوند. قبل از هر استفاده معاملاتی، زمان خبر را با منبع رسمی بررسی کن.

اگر تقویم تغییر کند یا endpoint از دسترس خارج شود، رفتار مورد انتظار سیستم توقف امن و حفظ `NO_TRADE` است؛ نه حدس زدن اینکه خبری وجود ندارد.
